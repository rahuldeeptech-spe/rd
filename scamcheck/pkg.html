Is this package safe to install?

Check an npm or PyPI package, or your dependency list, before you run npm install or pip install. Everything is read, nothing is executed.

🔒 Analysed inside your browser. Your files and dependency lists are never uploaded.

1. Scan a package file

Download the package without installing it, then drop the file here. These commands do not run any install scripts:

npm pack some-package@1.2.3 --ignore-scripts
pip download some-package==1.2.3 --no-deps

      Keep ScamCheck free

      This tool has no ads and no tracking. If it saved you or your family from a scam, a small contribution pays for development and hosting.

      This is a static, rule-based scan. It cannot catch every attack (especially new or heavily obfuscated ones) and it can occasionally flag a harmless package. Treat a clean result as "no known red flags", never as proof of safety. For anything that matters, read the source and pin versions with a lockfile.
