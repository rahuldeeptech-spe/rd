---------------------------------------------------------------------
3A. AI CHAT + CODING (Ollama)
---------------------------------------------------------------------
Step 3A.1  Install aur start:
             brew install ollama
             brew services start ollama
Step 3A.2  8GB ke liye sahi models (ek hi rakho, sab nahi):
             ollama run qwen3:4b        # sabse balanced (chat + code)
             ollama run gemma3:4b       # achha general chat
             ollama run llama3.2:3b     # sabse halka / fast
Step 3A.3  Chat band: /bye likho.
Step 3A.4  GUI chahiye to: LM Studio (free)
             brew install --cask lm-studio
           8GB par 3-4B size ke "Q4" quantized model hi download karo.
Step 3A.5  Coding agent (Claude Code jaisa, local model ke saath):
             pipx install aider-chat
             aider --model ollama_chat/qwen3:4b
           Note: 4B model ke saath agent chhote kaam hi theek karega.
Step 3A.6  Model hatana (space bachane):
             ollama list
             ollama rm <model-name>

---------------------------------------------------------------------
3B. IMAGE BANANA (Draw Things)
---------------------------------------------------------------------
Step 3B.1  Mac App Store kholo -> "Draw Things" search -> Get (free).
Step 3B.2  App me model download karo. 8GB ke liye:
             - SDXL Turbo / SDXL Lightning (fast, achhi quality)
             - SD 1.5 based models (sabse halke)
           Flux 8GB par chalega to sahi, par bahut slow.
Step 3B.3  Settings: resolution 768x768 ya 1024x1024 se zyada mat rakho.
Step 3B.4  Models external SSD par rakhne ka option settings me hai.

---------------------------------------------------------------------
3C. VOICE: TTS (Kokoro) + STT (whisper.cpp)
---------------------------------------------------------------------
TTS (text -> awaaz)
Step 3C.1  Python environment:
             brew install python@3.12 ffmpeg
             python3.12 -m venv ~/voice
             source ~/voice/bin/activate
             pip install -U pip mlx-audio
Step 3C.2  Kokoro model se awaaz banao. Exact command aur voice names
           yahan dekho: https://github.com/Blaizzy/mlx-audio
           (Kokoro sirf 82M size ka hai - 8GB par bahut fast chalta hai.)
Step 3C.3  Voice cloning sirf apni ya permission wali awaaz ki.

STT (awaaz -> text)
Step 3C.4  whisper.cpp:
             brew install whisper-cpp
             mkdir -p ~/whisper-models
             curl -L -o ~/whisper-models/ggml-small.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
Step 3C.5  Audio ko 16kHz WAV me badlo aur transcript banao:
             ffmpeg -i input.mp3 -ar 16000 -ac 1 audio.wav
             whisper-cli -m ~/whisper-models/ggml-small.bin -f audio.wav -l hi
           (-l hi = Hindi, -l en = English. 8GB par "small" model sahi hai.)

3E. CYBER LAB (8GB ke hisaab se)
---------------------------------------------------------------------
RULE: Sirf apne lab ya likhit permission wale targets par test karo.

OPTION 1 - Browser labs (RAM bachta hai, sabse best 8GB ke liye)
Step 3E.1  TryHackMe (AttackBox) aur HackTheBox (Pwnbox): Kali unke server
           par chalta hai, aapke browser me khulta hai.
Step 3E.2  Free practice: PortSwigger Web Security Academy, picoCTF,
           OverTheWire. Sab browser me, kuch install nahi.

OPTION 2 - Local lab (offline)
Step 3E.3  UTM install:
             brew install --cask utm
Step 3E.4  Kali Linux ARM64 image: kali.org/get-kali -> Virtual Machines
           -> UTM. UTM me import karo.
           Settings: RAM 3GB (3072 MB), CPU 2-4 cores. Disk external SSD par.
Step 3E.5  Docker ka halka engine (Docker Desktop se kam RAM leta hai):
             brew install colima docker
             colima start --cpu 2 --memory 2
Step 3E.6  Target app (ARM par chalta hai):
             docker run -d --name juice -p 3000:3000 bkimminich/juice-shop
           Browser me kholo: http://localhost:3000
           (Kai purane targets jaise DVWA ki images x86 hain; ARM Mac par
            dikkat ho to Juice Shop se shuru karo.)
Step 3E.7  Kaam khatam hone par RAM free karo:
             docker stop juice
             colima stop
Step 3E.8  Ek time par: YA Kali VM, YA Docker lab. Dono ek saath nahi.
Step 3E.9  Free tools (Mac par): Burp Suite Community, Wireshark, Ghidra
             brew install --cask burp-suite wireshark
             brew install ghidra
           (Ghidra ko Java chahiye: brew install openjdk@21)

4. FREE CLOUD GPU - "APNA" AI VIDEO / IMAGE
=====================================================================
Model aur settings aapke, GPU free cloud ka. Kling/ChatGPT ke kareeb
quality ka sabse aasaan FREE tareeka. (Ye Google/Kaggle par depend karta
hai, par software poora open-source aur aapke control me.)

  Platform            | Free GPU
  --------------------+-----------------------------------------------
  Kaggle Notebooks    | Har hafte kuch ghante free GPU (lagbhag 30 ghante;
                      | limit badal sakti hai). Phone verify zaruri.
  Google Colab (free) | Thoda free GPU, jitna available ho.
  Hugging Face Spaces | Doosron ke demo apps browser me (limited).

Step 4.1  kaggle.com par account banao -> Settings -> phone verify.
Step 4.2  New Notebook -> Settings -> Accelerator: GPU T4 x2 (ya P100).
          Internet: ON.
Step 4.3  ComfyUI install (notebook cell me):
            !git clone https://github.com/comfyanonymous/ComfyUI
            %cd ComfyUI
            !pip install -r requirements.txt
Step 4.4  Model download: Hugging Face se open model (image ke liye
          Flux schnell / SDXL; video ke liye Wan 2.x ka chhota version ya
          LTX-Video). Model files ComfyUI/models/ ke sahi folder me rakho.
          (Har model ka README dekho - folder aur file names wahan hain.)
Step 4.5  ComfyUI ko browser me kholne ke liye tunnel chahiye. Kaggle/Colab
          ComfyUI ke liye community notebooks hain - Kaggle par
          "ComfyUI" search karo, kisi popular notebook ko "Copy & Edit" karo.
Step 4.6  Ek baar me chhote clips (5-10 second) banao. Session khatam hone
          se pehle output download kar lo (session band = files gayab).
Step 4.7  Platform ke rules follow karo (Kaggle/Colab ki usage policy).

7. CLEANUP / RAM BACHANE KE TIPS
=====================================================================
- RAM check:            Activity Monitor -> Memory tab ("Memory Pressure"
                        green rehna chahiye; yellow/red = kuch band karo)
- Ollama band:          brew services stop ollama
- Docker band:          colima stop
- Browser tabs kam rakho (Chrome bahut RAM leta hai; Safari halka hai).
- Model / app hatana:
    ollama rm <model>
    brew uninstall <naam>
    brew uninstall --cask <naam>
    rm -rf ~/voice          # Python voice environment
