Step 0.1  macOS version check (Ollama / LM Studio ko macOS 14 Sonoma+ chahiye):
            sw_vers
Step 0.2  Homebrew install (agar nahi hai):
            /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
          End me jo "Next steps" ke 2 commands aaye, unhe chalao.
Step 0.3  pipx + Python 3.12 (kai voice tools 3.13 par nahi chalte):
            brew install pipx python@3.12 ffmpeg
            pipx ensurepath

          rakhoge to sab bahut dheere chalega.
          -> Ek sasti external SSD (USB-C, 256-512GB) le lo.
          -> Kali VM, Docker data, AI models, video projects usi par rakho.
Step 0.5  Free space check:
            df -h ~

3A. AI CHAT + CODING AGENT (Ollama + OpenCode)
---------------------------------------------------------------------
Step 3A.1  Ollama install (Apple Silicon par MLX/Metal se fast chalta hai):
             brew install ollama
             brew services start ollama
           (Ya ollama.com/download se DMG app.)
Step 3A.2  8GB ke liye model (EK hi rakho):
             ollama run qwen3.5:4b      # ~3GB, sabse balanced
             ollama run qwen3.5:2b      # aur halka/fast
           Purane tags bhi chalte hain: qwen3:4b, llama3.2:3b
           Exact tags yahan dekho: https://ollama.com/library
           9B model (~6GB) 8GB par mat chalao - Mac atak jayega.
Step 3A.3  Chat band: /bye
Step 3A.4  GUI chahiye to LM Studio (Apple Silicon + macOS 14+, 8GB par
           chhote model chalte hain):
             brew install --cask lm-studio
           Sirf 2-4B size ke 4-bit (Q4 / MLX 4bit) model lo.
Step 3A.5  Coding agent (Claude Code jaisa, open-source, MIT):
             brew install anomalyco/tap/opencode
             ollama launch opencode        # Ollama ke saath auto-setup
           Ya: opencode chalao -> /connect -> free cloud model chuno
           (Section 4 dekho - 8GB par cloud model zyada smart hai).
Step 3A.6  Claude Code ka interface local model par (free, par Claude jaisi
           quality NAHI - sirf tool/interface):
             ollama launch claude
Step 3A.7  Private data ke liye Ollama cloud band rakho:
           ~/.ollama/server.json me:  { "disable_ollama_cloud": true }
Step 3A.8  Model hatana:
             ollama list
             ollama rm <model-name>

3C. VOICE: TTS + STT
---------------------------------------------------------------------
ZERO INSTALL (abhi try karo): macOS ka built-in "say"
Step 3C.1  System Settings -> Accessibility -> Spoken Content -> System
           Voice -> Manage Voices -> Hindi voice download karo.
             say -v '?' | grep -i hi
             say -v <voice-name> "नमस्ते, ye mera Mac bol raha hai"

TTS - mlx-audio + Kokoro (Apple Silicon, free, commercial use OK)
Step 3C.2  Environment:
             python3.12 -m venv ~/voice
             source ~/voice/bin/activate
             pip install -U pip "mlx-audio[all]" misaki
Step 3C.3  Awaaz banao:
             mlx_audio.tts.generate --model mlx-community/Kokoro-82M-bf16 --text "Namaste" --play
           Kokoro sirf 82M hai - 8GB par bahut fast. Hindi basic quality.
Step 3C.4  Hindi ke liye halka offline option: Piper (hi_IN voice):
             pip install piper-tts
             python3 -m piper.download_voices        # list; hi_IN wali chuno
             python3 -m piper -m <voice> -f out.wav -- 'नमस्ते'
           (Thoda robotic, par 8GB par bhi aaram se.)
Step 3C.5  Hindi VOICE CLONING (Chatterbox Multilingual V3, MIT) - 16GB
           ke liye recommended; 8GB par slow / atak sakta hai.
           Sirf apni ya permission wali awaaz clone karo.

STT - whisper.cpp (Hindi + English)
Step 3C.6  Install (Homebrew formula ka naam ab "whisper.cpp" hai):
             brew install whisper.cpp
           Model khud download karna padta hai:
             mkdir -p ~/whisper-models
             curl -L -o ~/whisper-models/ggml-small.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.bin
Step 3C.7  Transcript:
             ffmpeg -i input.mp3 -ar 16000 -ac 1 audio.wav
             whisper-cli -m ~/whisper-models/ggml-small.bin -f audio.wav -l hi
           (-l hi = Hindi, -l en = English. 8GB par small/medium sahi.)
Step 3C.8  Alternative (MLX, fast):
             pip install mlx-whisper
             mlx_whisper audio.mp3 --model mlx-community/whisper-large-v3-turbo --language hi

OPTION 1 - Hosted labs (RAM nahi lagta) - sab free

Step 3E.3  pwn.college - poora free, browser me terminal + VS Code.
Step 3E.4  PortSwigger Web Security Academy - saare labs free (account).
Step 3E.5  TryHackMe free rooms. AttackBox free me 1 ghanta/din. Unlimited
           ke liye OpenVPN se apne Mac/Kali se connect karo:
             brew install openvpn
             sudo openvpn ~/Downloads/<aapka-naam>.ovpn
Step 3E.6  Hack The Box: free 20 active machines + Starting Point.
           Pwnbox free me sirf ek 2-ghante ka session (poori life me) ->
           OpenVPN use karo. HTB Academy Tier 0 modules free.
Step 3E.7  Blue team (defense): LetsDefend, Blue Team Labs Online,
           CyberDefenders - free tiers chhote hain, teeno rotate karo.

OPTION 2 - Local lab (offline)
Step 3E.8  UTM (stable 4.7.x):
             brew install --cask utm
Step 3E.9  Kali Linux ARM64 installer (2026.2 ya naya): kali.org/get-kali
           Official guide follow karo:
             https://www.kali.org/docs/virtualization/install-utm-guest-vm/
           (UTM -> Virtualize -> Other -> ARM64 ISO; guide ke hisaab se
            console/serial install, phir display set karo.)
           8GB ke liye: VM RAM 3GB (3072 MB), CPU 2-4, disk external SSD par.
Step 3E.10 Halka Docker engine (Docker Desktop se kam RAM):
             brew install colima docker
             colima start --cpu 2 --memory 2
Step 3E.11 Target: OWASP Juice Shop (ARM64 image available):
             docker run --rm -p 127.0.0.1:3000:3000 bkimminich/juice-shop
           Browser: http://localhost:3000   (127.0.0.1 = sirf aapka Mac)
Step 3E.12 Kaam khatam:  Ctrl+C,  phir  colima stop
Step 3E.13 Ek time par: YA Kali VM, YA Docker lab. Dono ek saath nahi.

FREE TOOLS (Mac native, Apple Silicon)

             brew install --cask burp-suite caido zap wireshark-app

7. KYA BAND HO GAYA / SCAM SE BACHO
=====================================================================
BAND / BADLA (2026) - purane blog posts par bharosa mat karo:
  - GitHub Models (free API)        -> 2026-07-30 ko band
  - Qwen Code free tier             -> 2026-04-15 ko band (tool abhi bhi
                                       local model ke saath chalta hai)
  - Roo Code extension              -> 2026-05-15 ko band (Cline / Kilo lo)
  - Continue                        -> read-only, maintain nahi hota
  - Cerebras no-card free tier      -> khatam
  - Groq Llama 3.1 8B / 3.3 70B     -> free tier se hata diye
  - Gemini Pro free API             -> khatam (sirf Flash, kam limit)
  - ISC2 CC free cert enrollment    -> 2026-05-20 ko band

SCAM / RISK - kabhi mat lo:
  - "Free unlimited Claude / GPT API" reseller ya proxy
  - Leaked / shared API keys (Telegram / Discord par bikti hain)
  - Kai free accounts bana ke limit badhane wale scripts
  - "Claude download karo / Claude GGUF" -> Claude ke weights public nahi
    hain, ye FAKE ya malware hai
  - Cracked Burp Pro / ElevenLabs / MacWhisper
  Ye sab terms ke khilaf hain, account ban hota hai, aur aapka code,
  password aur data chori ho sakta hai.

PRIVACY - inme free tier par aapka data training me ja sakta hai
(opt-out karo): Gemini CLI personal login, Gemini API free, Mistral free,
NVIDIA trial, kuch OpenCode Zen / OpenRouter free models, GitHub Copilot
Free, claude.ai (default ON - Settings me OFF karo).
